## 🌟 Fitur Utama Website

1. **360° Cinematic Background Canvas Engine**:
   - Menampilkan sequence foto 300 frame sebagai background interaktif menyeluruh.
   - Responsif terhadap usapan (*swipe*) layar di Android & iOS serta *mouse drag* di desktop dengan momentum inersia fisika.
   - Sinkronisasi rotasi sudut dinamis mengiringi gulir halaman (*scroll-driven animation*).
   - Mode tampilan ganda: *Full Seamless* (Ambient Glow) dan *Full Cover* (Edge-to-Edge).

2. **Ultra-Translucent Glassmorphism**:
   - Desain modern berbasis *dark luxury fintech* (obsidian slate, emerald glow, cyan accent).
   - Kartu deskripsi transparan sehingga gerakan latar belakang 360° terlihat dinamis di balik teks.
   - Tipografi kontras tinggi (*Plus Jakarta Sans* & *Space Grotesk*) yang tajam dan nyaman dibaca.

3. **Dokumentasi 3 Featured Projects**:
   - **Integrasi Database Surat Tugas**: Sistem input terstruktur dengan auto-numbering standar audit ([Lihat Spreadsheet](https://docs.google.com/spreadsheets/d/1QqtGHChhqYhWL7B-1TwIo4Xl0PLefFDyFW7GlY3Rfn8/preview)).
   - **Otomatisasi Memo & Kwitansi Utilitas**: Formula agregasi multi-wilayah dan cetak PDF memo otomatis ([Lihat Spreadsheet](https://docs.google.com/spreadsheets/d/1iJt2n8iuEkgXTGdUM_ZJ5Fi79vFhkej0KSOykWfjp-U/preview)).
   - **Dashboard Konfirmasi Pembayaran Utilitas**: Portal navigasi Dialogue Group per cabang ([Kunjungi Portal](https://linktr.ee/Pembayaranretribusi)).

4. **Mobile Native & Touch Optimized (Android & iOS Friendly)**:
   - Dukungan *Dynamic Viewport* (`100dvh`) bebas *jump* saat *address bar* browser muncul/hilang.
   - Pemanfaatan *safe area insets* (`env(safe-area-inset-top)` / `bottom`).
   - Area sentuh minimal 44px untuk kemudahan navigasi di smartphone.

## 🚀 Menjalankan Secara Lokal

1. Pastikan Node.js terinstall.
2. Jalankan server lokal:
   ```bash
   node server.mjs
   ```
3. Buka browser di [http://localhost:3000](http://localhost:3000).
